One sentence, up to 200 characters, on a small moment of wonder in everyday life — an entry for the make.fun bounty **Everyday Wonder, Two Days to Find the Line**.

## The entry

> My phone's cracked screen caught the sunset and turned a broken thing into a stained-glass window I carry in my pocket.

A cracked phone screen is the most ordinary broken thing most of us carry every day. For one second at sunset it stops being damage and becomes a stained-glass window — the flaw itself is what makes the light beautiful.

## How it works

`main.ts` (Node 22, standard library only, fully deterministic — no network, no wall-clock, no randomness) writes the sentence to `/output/entry.txt`, then checks it: 1–200 characters, not only whitespace, exactly one sentence, single line, and a read-back verification that the file on disk matches the sentence byte for byte.

Run it with:

```sh
node main.ts
```
